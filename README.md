# Nest Deploy

A Vercel-style dashboard for deploying projects to Hack Club Nest servers.

Status: early planning. Nothing is implemented yet.

Planning documents live in the project vault (`Project Ideas/04 Nest Deploy`).

## Planned

- Sign in with Hack Club Auth
- Connect a Nest server with a dedicated SSH key, added through the Nest dashboard
- Connect GitHub repositories
- Deploy, view logs, and roll back projects on Nest
